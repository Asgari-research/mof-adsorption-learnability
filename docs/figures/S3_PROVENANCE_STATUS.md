# Figure S3 provenance status

Figure S3 is retained as part of the current SI asset set and can be redrawn from the saved summary table.

The upstream historical pipeline maps ARC-MOF `Di -> PLD` and `Df -> LCD`, which conflicts with the conventional Zeo++ meanings used elsewhere in the project. The saved provenance currently available does not establish the exact historical external-column mapping used to compute the stored nearest-neighbor geometry distances.

Accordingly, redrawing the saved fractions is a visualization operation only. It does not repair or independently validate the historical external-overlap calculation. The external mapping should be verified from the original headers/mapping records before those distances are promoted as independently certified evidence.
